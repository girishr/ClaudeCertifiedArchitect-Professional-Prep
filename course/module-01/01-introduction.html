Module introduction

The four decisions that happen before anyone writes code.

Official screens S01~2 min in the original
CCAR-P course / Module 1 / Section 01 of 12

Anthropic's Module 1 opens by naming four decisions. They happen before a line of code exists, they are made in order, and every later choice inherits them.

The module is not asking you to memorise these as stages. It is training you to recognise which of the four is in front of you, because each one rewards a different move. The instinct that serves you in decomposition is the wrong instinct when you are picking an entry point.

1.1What the module says you will be able to do

Six objectives, in the module's own framing, compressed:

  1. Break a partner request into Claude work, system work and human work, using the four model properties as the lens.
  2. Choose between an augmented call, a workflow and an agent by naming what each choice costs.
  3. Pick a reference architecture for the problem shape, and spot retrieval doing a job that live state should own.
  4. Make defensible model, context-window and context-strategy calls, with evaluation as the gate on any model swap.
  5. Place each platform entry point, and know what customisation belongs at which layer.
  6. Keep entry points, build-time interfaces and delivery routes distinct, and let governance rule options out before any other tradeoff applies.
The role being trained

The architect who turns an ambiguous partner request into something someone can build, fund and defend. You are not writing the production code here. You are making the decisions that sit above it, in front of an enterprise buyer, often in a regulated setting, where a choice that looked clean in a demo turns up as a misroute in an audit three months later.

1.2How this version maps to the official one

The official module is 34 screens across 12 sections, 238 minutes of reading, with 11 checkpoints and 2 exercises. This course keeps the same 12 sections in the same order, so you can move between the two without losing your place. Every section here names the screens it covers.

The text is not Anthropic's. It is written from the module, not copied from it, and the drills are my own. If a distinction matters to the exam, it is here. If a paragraph exists in the original only to introduce the next paragraph, it is not.
