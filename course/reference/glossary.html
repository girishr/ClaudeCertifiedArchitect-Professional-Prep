Glossary

The course speaks this vocabulary. Where a term is contested, the Anthropic usage wins.

ArchitectureShapes and tiers

Augmented LLMA single model call with retrieval, tools and memory attached. The baseline every other architecture must beat before you are allowed to build it.
WorkflowLLMs and tools orchestrated through predefined code paths. You wrote the path. Predictable cost, latency and audit trail.
AgentThe model dynamically directs its own process and tool use. The path is decided at runtime, by the model.
Prompt chainingFixed sequence of calls, each consuming the last. Optional programmatic gate between steps.
RoutingClassify the input, then dispatch to a specialised downstream path. Only safe when classification is accurate.
SectioningParallelisation where you split the work in code before runtime. Independent subtasks, concurrent execution.
VotingParallelisation where the same task runs N times and you aggregate. Buys confidence at N times the cost.
Orchestrator-workersA lead model decomposes the task at runtime and delegates to workers. Use only when the subtask set genuinely depends on the input.
Evaluator-optimizerOne call generates, another critiques against criteria, loop until good enough. Needs articulable criteria.
Blast radiusHow much damage a wrong action does before anyone notices. Drives where the human checkpoint goes.
Binding constraintThe one requirement in a scenario that eliminates otherwise-good answers. Usually latency, compliance, cost, reversibility or team maturity.
Rainbow deploymentGradual traffic shift across versions so long-running agents are not killed mid-run by a deploy.

ModelsReasoning and cost controls

Adaptive thinkingthinking: {type: "adaptive"}. Supported from Claude 4.6 onward. The model decides per request whether to think at all.
Extended thinkingThe older type: "enabled" plus budget_tokens. Deprecated on 4.6, returns a 400 on 4.7+.
Effortoutput_config.effort. Five levels: low, medium, high, xhigh, max. Default is high, and setting it explicitly is identical to omitting it.
Prompt cachingReuse of a static prefix across calls. Up to 4 breakpoints. Writes cost 1.25x (5 min) or 2x (1 hour); reads cost 0.1x. Order: tools, then system, then messages.
Cache minimumShortest cacheable prefix, and it varies by model: 512, 1,024, 2,048 or 4,096 tokens. Below it, caching is skipped silently with no error.
Batch APIAsynchronous processing at 50% off input and output. Most complete inside an hour, 24 hour ceiling. Wrong answer for anything interactive.
Context rotDegradation of recall as context grows. Attention is a finite budget, so more context is not free.
CompactionSummarising conversation history to reclaim context window while preserving the thread.
Just-in-time retrievalFetching context when needed rather than stuffing it up front. The counter-move to context rot.
Progressive disclosureExposing capability metadata cheaply and loading the body only on use. How Skills and tool search keep context small.

ExamTerms of art

CCAR-PClaude Certified Architect - Professional. 120 minutes, scaled score 100 to 1000, pass mark 720.
Scaled scoreNot a percentage of items correct. Do not convert 720 into "questions I can miss".
DistractorA wrong option. On this exam they are real techniques applied at the wrong time, not nonsense.
Multiple response"Select TWO" or "Select THREE". The correct answers usually sit at different layers, one architectural and one operational.
