Claude Platform & Solution Design

Seven short lessons covering the same ground as Anthropic's 238-minute course, broken so each one fits an evening and gives you one tangible win.

~2 hours across 7 lessons 35 scenario drills Exam Domains 1 and 2, 30% of the paper

This track shadows Course 1 of the official CCAR-P Prep Course. The lesson sequence follows Anthropic's own published learning objectives for that course, not a structure I invented. Their course page lists six objectives, and each one gets a lesson or two below.

How to use this

Read in order the first time. The lessons build: the tier decision comes before the pattern, the pattern before the surface, the surface before the governance. After that, jump straight to whichever drill set you are weakest on, and use the two reference documents for revision rather than re-reading lessons.

Short on time? Start here

Module 1 Distilled is the whole official course in one pass, about 45 minutes: the four properties, the seven primitives, decomposition, pattern selection, reference architectures, RAG, model and context strategy, prompting, entry points and governance, with 9 drills. Read that alone and you have the module. The seven lessons below drill individual decisions harder.

One honest caveat

The official course's granular module list is behind enrolment. What is public is the set of learning objectives, and those are what this sequence follows. The lesson split is mine. If you enrol and find the real breakdown differs, tell me and I will restructure rather than defend the guess.

I am your teacher for this course, so use me. If a drill felt like a coin flip, name it and we will pull the constraint apart. If you think an answer is wrong, argue it, because that is usually where the interesting distinction lives. And if the pitch is too easy or too hard, say so and I will move it.
