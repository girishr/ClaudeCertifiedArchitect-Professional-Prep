Scope: the CCAR-P prep hub (`index.html`, generated from `tools/hub-template.html`) plus the shared course shell it links to: `course/assets/lesson.css`, `course/assets/nav.css`, `course/assets/nav.js`, `course/index.html` and the reference pages. Visitor mode: Operate. The hub is a workbench, not a brochure.

Audience and job: candidates preparing for Anthropic's CCAR-P exam, at Partner Network organisations, working in two situations - long reading sessions through a module, and short timed drill sessions. The job is to find out which of seven weighted domains will fail them, and to fix it before the exam. Action: start the course, run a set, read the score.

Fixed by the user in this round: the question bank, the three quiz modes, the scoring maths and the per-domain results logic do not change; no prose copy, heading, explanation or exam fact is rewritten; the official badge and the Anthropic attribution and links stay visible. One reframing is in scope and was approved with the audience answer: the fixed 5 Sep 2026 countdown and the calendar-dated 21-day plan become a relative plan any visitor can start on any day, with the exam date set by the visitor.

Unresolved: none blocking. Modules 2 to 5 remain official-links-only until distilled.

## Direction contract

THESIS: A certificate is a document that resists forgery by being unreproducibly precise, and so is an honestly weighted score report. This site is built out of the printing craft that credentials are actually made from - intaglio line work, guilloche, engraved numerals, security tints, plate serials - so the instrument feels issued rather than assembled. It refuses the arrangement this category always ships: same-size rounded cards on a near-black ground with one blue accent and a progress bar, which is exactly what the incumbent hub is.

OWN-WORLD: Two inks on a tinted stock, never more. Dark is the steel plate: a green-black ground (#0c1310), warm ink-white text, intaglio green (#3ba57c) and oxblood (#c9636a) as line work, seal gold (#c9a24a) for the pass mark alone. Light is tinted safety stock (#e4e7dd), deep intaglio green (#0e6b4d) and oxblood (#8c1f2d). Hairline rules at 1px, square corners everywhere, no shadows, no fills that are not ink, no gradients. Bodoni Moda engraves display and numerals, Faustina sets long-form reading, Archivo sets the workbench, Chivo Mono sets serials and tabular figures - all self-hosted. Ornament lives only in structure: plate borders, ruled indexes, serial strips, seals. It never enters a question body or a timed screen.

STORY: A visitor lands and understands in seconds that this is the official path's practice layer, built by someone who followed it, with the exam's real numbers printed on the sheet. They start Module 1 or run a set. They come back to read the rosette, see which lobe is thin, and go fix that domain.

FIRST VIEWPORT: A certificate header. A ruled plate line across the top, the official badge at left as the seal, the full credential name engraved in Bodoni at display size with the existing standfirst beneath it, and to the right a serial strip in mono carrying the exam's own facts - 63 items, 120 minutes, 720 to pass, 7 domains - with the visitor's own exam date settable there. Below it the existing Module 1 call to action as the one filled ink block on the sheet, then the five tabs as a ruled ledger index rather than pills. The calibration rosette - seven guilloche lobes drawn live in canvas from the published domain weights, line density set by accuracy, the 720 pass mark as a dashed gold ring - is the signature interaction and owns the Results tab.

FORM: Security Print, candidate 7 of 7 on the ordered grounded list, assigned by the roll; seed key 3bea8e31. Roll ran degraded - no catalog challengers and no quality-bar boards, disclosed to the user. Build path: code-led, because no image generation is reachable from this sandbox.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
