# ClaudeCertifiedArchitect-Professional-Prep Development Context

## Project Memory

### Constraints

GitHub Pages static hosting only: no server, no build step beyond `python3 tools/build_hub.py`, which regenerates `index.html` from `tools/hub-template.html`, `questions.json` and the `PLAN` literal in the script. `index.html` is generated and must never be hand-edited. Course pages under `course/` are hand-edited HTML sharing `course/assets/lesson.css`, `nav.css` and `nav.js`. Zero runtime dependencies; no budget.

## The one thing most likely to go wrong

**Editing `index.html` directly.** It is 215 KB of generated output and looks perfectly editable. The next `build_hub.py` run discards the edit without warning. Every hub change belongs in one of three places:

| To change | Edit |
|---|---|
| Hub layout, styling or JS | `tools/hub-template.html` |
| Questions, explanations, distractor notes | `questions.json` |
| The 21-day study plan | the `PLAN` literal in `tools/build_hub.py` |

Then run `python3 tools/build_hub.py` and commit the regenerated `index.html` alongside the source change.

## Content is fixed unless asked

This repo is unusual: the prose *is* the product. Question bank contents, quiz behaviour, scoring maths, per-domain results logic, copy, headings, explanations and exam facts are all fixed (REQ-007). Do not tidy, rephrase or "improve" them. The single live exception is the study-plan reframe (REQ-003.2).

Exam facts come from Anthropic's official CCAR-P Exam Guide, obtained 20 Aug 2026. Nothing may be claimed that the guide does not confirm — and there are no testimonials, pass rates, user counts or endorsements to draw on, so none may be invented.

## Two provenances in the course

Module 1 was distilled from Anthropic's official module. Modules 2–5 were built from this repo's own domain notes, because the official content sits behind Partner Academy enrolment. Every module 2–5 page says so, and must keep saying so (REQ-004.3).

## Known gaps

- No tests and no CI — deliberate for now, recorded in `quality/tests.md`.
- The study-plan reframe (REQ-003.2) is in progress: the plan still carries weekday labels and a fixed 5 Sep 2026 exam date in places.
- Shared behaviour is duplicated across 55 hand-edited course pages; a change to nav or lesson structure touches many files.

## Accessibility commitments that must survive

Self-hosted OpenDyslexic on course pages, real contrast, keyboard-operable controls, honest focus states, and pages that print usefully (`course/assets/print.css`; the pattern-selection sheet is an explicit print target). These are requirements, not preferences — see REQ-008.
